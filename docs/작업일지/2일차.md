# 2일차 작업일지 (2026-11-13)

## 어제 작업내용

기획서를 바탕으로 편집기 **trackcut**을 Rust로 만들기 시작했다. 자세한 내용은 [1일차](1일차.md)에 있다.

| 영역 | 내용 |
|---|---|
| 코어 | flick 정수 시간 계산, 미디어 분석(VFR 포함), 트랙 이름표, 프로젝트 파일(JSON) |
| 편집 동작 | 분할, 구간 삭제, 트림, 이동, 연결/해제, 볼륨·음소거·솔로, Undo/Redo |
| 명령줄 도구 | `trackcut probe / tag / new / split / delete / show / export` |
| 편집 화면 | 미리보기, 타임라인, 믹서, 단축키, 휠 확대·축소 |
| 미리보기 | 요청한 프레임과 화면 프레임이 정확히 일치하는 디코더 |
| 내보내기 | 섞어서 하나로, 다중 트랙, 트랙별 WAV. NVENC 우선, 진행률·취소 |
| 소리 | 캐시한 PCM을 실시간으로 섞어 재생, 파형 표시 |
| 저장소 | 공개 저장소, 개인정보·컴퓨터 정보 자동 검사(커밋 훅 + CI) |

결정한 것: 화면까지 전부 Rust(egui), 영상 처리는 `ffmpeg` 프로세스, 빌드 출력은 영문 경로.

## 현재 작업내용

화면에서 직접 편집할 수 있는 기능을 넣고, 사용자 요청에 맞춰 화면 구성을 바꿨다. 테스트 48개가 통과한다.

### 만든 것

| 영역 | 내용 | 확인 방법 |
|---|---|---|
| 마우스 편집 | 클립·트랙 선택, 끌어서 이동·트림, 연결 해제(U), 트랙 이름 바꾸기, M 키 음소거. 한 번 끈 것은 Undo 한 단계 | 끌기 단위 테스트, 화면 캡처 |
| 실행 파일 | `trackcut.bat`을 두 번 누르면 개발용 빌드로 실행. 영상 파일을 위에 놓으면 그 파일로 열림 | 빌드와 실행 파일 찾기까지 |
| 미리보기 화질 | 540p로 줄이던 것을 원본 해상도 기본으로 변경. 720p·540p 선택 가능 | 화면 캡처 |
| 재생 속도 | 클립마다 25~400%. 뒤쪽 클립이 밀리거나 당겨짐. 소리는 음높이도 함께 바뀜 | 단위 테스트, 실제 샘플 내보내기(200%: 965 → 482프레임) |
| 화면 자르기 | 미리보기의 빨간 테두리와 손잡이 8개를 끌어 자름. 미리보기와 내보내기에 같게 반영 | 단위 테스트, 내보낸 프레임과 화면 캡처 비교 |
| 여러 파일 | 파일을 더 놓으면 타임라인 끝의 같은 트랙에 이어 붙임 | 단위 테스트, 두 파일 화면 캡처 |
| 구역 | 타임라인을 두 번 눌러 구역을 여러 개 지정. 선을 끌어 조절. 우클릭 메뉴로 구역 분할·삭제·표시 지우기 | 화면 캡처(표시만) |
| 분할 방식 | 구역의 양 끝에서 나누는 것만 남김. 재생 위치 기준 분할(S 키)은 제거 | 빌드 |
| 클립 제목과 순서 | 클립 위에 "영상 N · 분할 K" 제목 띠. 선택한 클립은 밝게 표시. 이웃 클립과 순서 바꾸기 | 단위 테스트, 화면 캡처 |
| 상단 메뉴바 | 왼쪽에 저장·내보내기·되돌리기, 가운데에 재생·프레임 이동, 오른쪽에 지금 위치 | 화면 캡처 |
| 왼쪽 패널 | 영상을 고르면 영상 편집(속도, 자르기, 출력 해상도), 오디오를 고르면 오디오 편집(볼륨, 소리 보정). "순서", "프로젝트", "단축키" 탭 | 화면 캡처 |
| 소리 보정 | 노이즈 제거, 저음 잡음 차단, 3밴드 이퀄라이저. 원본 트랙은 음소거만 하고 보정한 소리를 바로 아래 새 트랙에 올림 | 단위 테스트, 실제 ffmpeg 테스트 |
| 숫자 칸 Undo | 한 칸을 연달아 고친 것은 Undo 한 단계로 묶음. 믹서 볼륨도 되돌릴 수 있음 | 단위 테스트 |

### 결정한 것

| 결정 | 이유 |
|---|---|
| 속도를 바꾸면 소리의 음높이도 함께 바뀐다 | 미리듣기(선형 보간)와 내보내기(`asetrate`)의 결과를 같게 하기 위해서다. 음높이 유지는 나중에 넣는다. |
| 자른 화면은 비율을 지킨 채 화면에 맞춰 키우고 남는 곳은 검게 채운다 | 화면이 찌그러지지 않게 한다. |
| 구역은 프로젝트 파일에 저장하지 않는다 | 편집 결과가 아니라 화면 상태다. |
| 개발용 빌드에서도 외부 라이브러리는 최적화한다 | 원본 화질 미리보기가 끊기지 않게 한다. |
| 보정한 소리는 영상 옆 `.trackcut-audio` 폴더에 FLAC으로 둔다 | 원본을 건드리지 않고, 같은 설정이면 다시 만들지 않는다. |

### 아직 확인하지 못한 것

- 마우스 조작 전부: 클립 끌기, 구역 선 끌기, 자르기 손잡이, 우클릭 메뉴, 순서 바꾸기 버튼, 숫자 칸
- 소리를 귀로 듣는 확인: 재생, 속도를 바꾼 클립, 보정한 트랙
- 원본 화질 미리보기가 재생 중에 끊기지 않는지
- 오디오 6트랙 녹화본, 30~40분 파일의 처리 속도

### 알아둘 한계

- 구역은 프로그램을 다시 열면 사라진다.
- 소리 보정은 트랙 전체에 한 번에 적용한다. 설정을 바꾸려면 새 트랙을 다시 만든다.
- 출력 해상도 변경과 파일 추가의 미디어 목록은 되돌리기에 들어가지 않는다.
- 여러 클립을 한꺼번에 선택할 수 없고, 클립 복사·붙여넣기가 없다.
- 내보내기는 전체를 다시 인코딩한다. 영상 트랙이 여러 개면 첫 번째만 내보낸다.

## 추가계획

### 사용자 요청 (우선)

1. **여러 영상에 걸친 구역 분할**: 선택한 구역이 여러 영상을 동시에 잡고 있으면, 분할된 부분을 영상마다 따로 두지 않고 하나의 구간으로 만든다.
2. **구역 재생**: 구역을 선택한 채 재생하면 보고 있는 프레임부터 그 구역의 끝까지만 재생한다.
3. **구역 다중 선택과 병합**: Shift + 좌클릭으로 구역을 여러 개 선택한다. 다중 선택한 채로 우클릭하면 "병합" 메뉴가 나오고, 하나의 구역으로 합친다.
4. **원본 타임라인과 편집 타임라인**: 하나의 타임라인 안에 위쪽은 원본(영상 + 오디오 트랙), 아래쪽은 편집본(영상 + 오디오 트랙)을 같은 시간축에 둔다. 분할한 구역을 클릭해 끌어서 편집 쪽에 놓으면 그 구역이 복사되어 올라간다. 원본과 편집본을 크게 두 묶음의 트랙으로 본다.
5. **초보자용 편집 탭**: 왼쪽 편집 탭의 조절을 숫자 입력과 쉬운 조절 도구(슬라이더, 미리 정한 값 버튼 등)를 함께 두어, 편집을 몰라도 쉽고 간단하게 쓸 수 있게 한다.
6. **믹서 정리**: 미리보기 오른쪽 믹서가 무슨 기능인지 초보자가 알기 어렵다. 필요한 기능이면 알기 쉽게 남기고, 왼쪽 패널과 겹쳐 필요 없으면 제거한다.
7. **화면 배치 조절과 유지**: 패널의 위치와 크기를 사용자가 자기에게 맞게 바꿀 수 있게 하고, 그 설정을 저장해 다음 실행에도 유지한다.

### 사용자 결정이 필요한 것

- **AI 업스케일링**: 외부 AI 모델이 필요하다. 지금은 Lanczos 방식으로 해상도만 키운다.
- **TTS 변환**: 음성을 글로 바꾸는 엔진과 글을 읽는 엔진이 필요하다.
- 둘 다 PC에 설치해 쓰는 무료 도구로 할지, 유료 온라인 서비스로 할지 정해야 한다.

### 이전 계획에서 남은 것

1. 자동 저장과 불러오기 진행률 표시

3. 여러 영상 트랙 합성, 클립 복사·붙여넣기, 여러 클립 선택
4. 전환 효과: 내보내기는 `xfade`, 미리보기는 셰이더
5. 스마트 렌더: 손대지 않은 구간은 원본을 그대로 복사. FFV1, MKV + FLAC 내보내기 옵션
6. AI 조작(MCP): 편집기 안의 MCP 서버와 작업 표시 화면
7. OBS 스크립트: 녹화가 끝나면 자동으로 이름표 넣기
8. 썸네일 띠, 음성 변조, 속도를 바꿔도 음높이 유지
