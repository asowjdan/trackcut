# 3일차 작업일지 (2026-11-13)

## 어제 작업내용

화면에서 직접 편집하는 기능을 넣고 화면 구성을 바꿨다. 자세한 내용은 [2일차](2일차.md)에 있다.

| 영역 | 내용 |
|---|---|
| 마우스 편집 | 클립 선택, 끌어서 이동·트림, 연결 해제, 트랙 이름 바꾸기 |
| 클립 설정 | 재생 속도(25~400%), 화면 자르기, 여러 파일 이어 붙이기 |
| 구역 | 타임라인에 구역을 여러 개 지정하고 구역 단위로 분할·삭제 |
| 화면 | 상단 메뉴바, 선택에 따라 바뀌는 왼쪽 패널, 클립 제목과 순서 바꾸기 |
| 소리 | 노이즈 제거·저음 잡음 차단·이퀄라이저로 보정한 새 트랙 만들기 |

## 현재 작업내용

2일차의 "사용자 요청 (우선)" 7개를 모두 구현했다. 테스트는 48개에서 70개로 늘었고 전부 통과한다.

### 끝낸 항목

| 번호 | 요청 | 구현한 내용 | 확인한 방법 |
|---|---|---|---|
| 1 | 여러 영상에 걸친 구역 분할 | 구역을 분할하면 그 안의 조각을 전부 하나의 연결 묶음으로 만든다. 제목 앞에 "구간 N"이 붙고, 하나를 누르면 함께 선택되고 함께 움직인다. 순서 바꾸기도 구간을 통째로 옮긴다 | 단위 테스트 3개, 두 파일에 걸친 구역을 분할한 화면 캡처 |
| 2 | 구역 재생 | 구역을 선택한 채 재생하면 보고 있는 프레임부터 그 구역의 끝에서 멈춘다. 구역 밖을 누르면 선택이 풀려 끝까지 재생한다 | 단위 테스트 2개, 0.5초에서 재생해 구역 끝(1.5초, 90프레임)에서 멈춘 화면 캡처 |
| 3 | 구역 다중 선택과 병합 | Shift + 좌클릭으로 구역을 여러 개 고른다(다시 누르면 빠진다). 고른 구역 위에서 우클릭하면 "병합"이 나오고, 왼쪽 패널에도 병합 버튼이 생긴다. 가장 이른 시작부터 가장 늦은 끝까지가 한 구역이 된다 | 단위 테스트 4개, 구역 3개를 합친 화면 캡처 |
| 4 | 원본 타임라인과 편집 타임라인 | 타임라인 위쪽은 "원본", 아래쪽은 "편집본" 묶음이고 같은 시간축을 쓴다. 원본 클립을 편집본 쪽으로 끌면 놓일 자리가 미리 보이고, 놓으면 복사된다. 원본은 그대로 남는다 | 단위 테스트 6개, 편집본을 실제 파일로 내보내 프레임 번호를 되읽는 테스트 1개, 구역 2개를 복사한 화면 캡처 |
| 5 | 초보자용 편집 탭 | 값마다 슬라이더(옆 숫자 칸에 직접 입력 가능)와 미리 정한 값 버튼을 함께 뒀다. 속도 "0.5배~4배", 자르기 "정사각형·세로 9:16", 볼륨 "조용히~크게", 소리 보정 "목소리 또렷하게" 등 | 단위 테스트 2개, 영상·오디오 편집 탭 화면 캡처 |
| 6 | 믹서 정리 | 미리보기 오른쪽 믹서를 **제거**했다. 대신 오디오 트랙 이름 옆에 "켜짐 / 꺼짐" 버튼을 뒀다 | 화면 캡처 |
| 7 | 화면 배치 조절과 유지 | 상단 오른쪽 "화면 배치" 메뉴로 편집 패널(왼쪽·오른쪽·숨김)과 타임라인(아래·위)의 위치를 바꾸고, 경계선을 끌어 크기를 바꾼다. 배치와 창 크기를 설정 파일에 자동 저장한다 | 단위 테스트 4개, 임시 설정 폴더에 저장한 뒤 다시 실행해 같은 배치로 열리는 화면 캡처 |

### 항목별로 정한 것

| 결정 | 이유 |
|---|---|
| 믹서는 고쳐서 남기지 않고 제거했다(6번) | 믹서의 기능(볼륨, 음소거, 솔로)이 왼쪽 패널의 오디오 편집과 전부 겹쳤다. 믹서만의 장점은 트랙을 고르지 않고 여러 트랙을 한눈에 켜고 끄는 것뿐이어서, 그 기능만 타임라인의 트랙 이름 옆 버튼으로 옮겼다. 미리보기가 그만큼 넓어졌다. |
| 재생 위치가 구역 밖이면 구역의 시작부터 재생한다(2번) | "보고 있는 프레임부터"를 그대로 따르면 구역 뒤에서는 재생할 것이 없다. 구역 끝에서 다시 누르면 구역을 다시 재생한다. |
| 병합하면 구역 사이의 빈 곳도 한 구역에 들어간다(3번) | 구역은 시작과 끝 하나씩으로 된 범위라서, 떨어진 구역을 합치면 가장 이른 시작부터 가장 늦은 끝까지가 된다. |
| 편집본 트랙은 원본 트랙마다 하나씩 짝을 지어 만든다(4번) | 게임·마이크처럼 나뉜 소리를 편집본에서도 따로 다듬을 수 있어야 한다. 처음 복사할 때 "편집 · 영상", "편집 · 오디오 1"처럼 자동으로 생긴다. |
| 끌어다 놓은 자리가 다른 편집본 클립과 겹치면 편집본의 맨 끝에 놓는다(4번) | 겹친다고 거절하는 것보다 어디든 올라가는 편이 쓰기 쉽다. 우클릭 메뉴와 왼쪽 패널의 "복사"는 처음부터 맨 끝에 붙인다. |
| 미리보기와 소리는 원본과 편집본 중 하나만 따른다(4번) | 같은 시간축에 두 묶음이 겹쳐 있어 둘을 함께 재생할 수 없다. 상단의 "보기"로 고르고, 클립이나 트랙을 누르면 그 묶음으로 바뀐다. 구역 분할·삭제도 보고 있는 묶음에만 적용한다. |
| 내보내기는 편집본에 올린 것이 있으면 편집본을, 없으면 원본을 내보낸다(4번) | 편집본을 쓰지 않던 기존 방식(원본을 직접 자르기)도 그대로 쓸 수 있게 했다. 내보내기 창에 어느 쪽을 내보내는지 적어 뒀다. |
| 패널 위치는 끌어서 붙이는 방식이 아니라 메뉴에서 고른다(7번) | 패널이 둘뿐이라 메뉴가 더 단순하고 실수로 배치가 흐트러지지 않는다. 크기는 경계선을 끌어 바꾼다. |
| 화면 배치는 프로젝트 파일이 아니라 사용자 설정 폴더(`trackcut/layout.json`)에 둔다(7번) | 어느 영상을 열든 같은 배치여야 한다. |

### 함께 고친 것

- 속도 변경이 연결 묶음 전체가 아니라 같은 시간대의 클립에만 적용되게 했다(여러 조각을 묶은 구간 때문).
- 솔로는 같은 묶음(원본 또는 편집본) 안에서만 다른 트랙을 끈다.
- 구역을 삭제할 때 걸쳐 있던 다른 구역이 사라지지 않고 잘린 만큼만 줄어든다.
- 파일을 열기 전에 타임라인 패널이 내용 높이로 줄어들던 문제를 고쳤다. 타임라인이 낮으면 트랙 줄 높이를 줄인다.
- 구역 관련 코드는 `regions.rs`, 편집 탭은 `app/edit_tab.rs`, 화면 배치는 `layout.rs`로 나눴다.
- 화면 확인용 실행 인자를 늘렸다: `--region`(여러 번), `--split`, `--merge`, `--to-edit`, `--edit-view`, `--panel-right`, `--timeline-top`.

### 확인하지 못한 것

화면 캡처는 실행 인자로 상태를 만든 뒤 찍은 것이라, 실제 마우스·키보드 조작은 하나도 해 보지 못했다. 직접 확인이 필요하다.

- **4번의 끌어다 놓기**: 원본 클립을 편집본 쪽으로 끌 때 놓일 자리 표시가 따라오는지, 놓으면 그 자리에 복사되는지, 원본 클립이 제자리에 남는지. 복사 동작 자체는 테스트했지만 끌기 조작은 코드로만 확인했다.
- **3번의 Shift + 좌클릭과 우클릭 "병합" 메뉴**: 병합 계산은 테스트했고, 클릭과 메뉴는 해 보지 못했다.
- **6번의 "켜짐 / 꺼짐" 버튼**, **7번의 "화면 배치" 메뉴와 경계선 끌기**: 그려지는 것만 확인했다. 실제 설정 폴더에 저장되는지도 직접 실행해 봐야 한다(확인은 임시 폴더로 했다).
- **5번의 슬라이더와 버튼**: 눌렀을 때의 반응. 좁은 패널에서 버튼이 두 줄로 넘어가는 모양이 괜찮은지.
- 편집본을 보면서 재생할 때의 소리, 구역 끝에서 소리가 깔끔하게 멈추는지.
- 모니터가 1대뿐이어서 화면 캡처용 창이 쓰고 있는 화면에 잠깐 떴다(포커스는 가져가지 않는다).
- 2일차에서 남은 것: 클립 끌기, 자르기 손잡이, 귀로 듣는 확인, 6트랙·30~40분 파일의 처리 속도.

### 알아둘 한계

- 편집본 클립을 다른 트랙으로 옮길 수 없다(같은 트랙 안에서만 이동한다). 편집본 클립 삭제는 구역을 지정해 "삭제"하는 방법뿐이다.
- 원본을 고쳐도 이미 복사한 편집본에는 반영되지 않는다(복사한 시점의 내용이 남는다).
- 편집본에서 원본으로 되돌려 복사하는 기능은 없다.
- 타임라인에 트랙이 많으면 줄 높이가 30px까지 줄고, 그래도 넘치면 패널을 키워야 보인다(세로 스크롤이 없다).
- 시각을 프레임에 맞출 때는 그 시각에 있는 영상 클립 가운데 먼저 찾은 것의 프레임을 따른다. 원본과 편집본의 같은 시각에 프레임 시각이 다른 영상이 있으면 한 프레임 안쪽의 차이가 날 수 있다.
- 구역과 "보기" 선택은 프로그램을 다시 열면 사라진다.
